Main — Enhanced Master Prompt (Quality Standards)

3k chars combined

Context & Notes

Your current prompt is already good, but it has two weaknesses if you're going to use it with Gemini, Claude, ChatGPT, or any other LLM:

1. It specifies topics but not output quality standards.

  • Models may give shallow content.
  • They may skip internals.
  • They may stop after a few pages.

2. It doesn't enforce architect-level depth.

  • A model may teach "what is HashMap" but not:
  • HashMap internals
  • Memory layout
  • Performance tradeoffs
  • Production issues
  • Interview questions
  • Architect decision making

3. It doesn't define a document generation strategy.

  • Asking for a 100+ page DOCX in one shot usually fails because of context limits.
  • Better approach: generate one lesson/chapter at a time, then combine.

---

What I Would Change

Add these requirements:

1. Act as Multiple Experts

Instead of:

```text

You are my Java mentor

```

Use:

```text

You are simultaneously:

  • Senior Java Engineer (15+ years)
  • Staff Engineer
  • JVM Expert
  • Spring Expert
  • Distributed Systems Expert
  • Solution Architect
  • Technical Interviewer
  • University Professor

Teach from all these perspectives.

```

---

2. Force Multi-Level Explanations

For every topic:

```text

Explain at five levels:

Level 1: Beginner

Level 2: Intermediate

Level 3: Senior Developer

Level 4: Staff Engineer

Level 5: Solution Architect

```

This dramatically improves quality.

---

3. Force Internal Mechanics

Add:

```text

For every API, class, annotation, framework, pattern, collection,

concurrency utility, Spring feature, Kafka concept, cloud service,

or design pattern explain:

1. What it is

2. Why it exists

3. What problem it solves

4. Internal implementation

5. Memory impact

6. Performance impact

7. Thread-safety considerations

8. Scalability considerations

9. Production usage

10. Common interview questions

11. Common mistakes

12. Alternatives

13. When not to use it

```

---

4. Add Architect Decision Tables

Require:

```text

Every lesson must include:

Decision Matrix

Trade-Off Matrix

Production Recommendations

Architect Notes

```

Example:

| Requirement | Use |

|------------|------------|

| Fast lookup | HashMap |

| Ordered lookup | LinkedHashMap |

| Concurrent lookup | ConcurrentHashMap |

---

5. Force Visualizations

Add:

```text

Every lesson must include:

Architecture diagrams

Memory diagrams

Execution flow diagrams

```
